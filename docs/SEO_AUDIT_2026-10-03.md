# Nitaq Academy SEO audit and local implementation — 2026-10-03

Scope: the existing React/Vite project and the public `https://www.nitaqacademy.com/` site. This is a local implementation report, not a production deployment or a Search Console report. The repository already contained extensive unrelated uncommitted changes, so no branch switch or commit was made. The current homepage layout, section order, navigation and conversion flow were retained.

**Search Console evidence unavailable; indexing and ranking conclusions are limited.** Google Business Profile, GA4 account, and server/CDN dashboards were also unavailable. No field Core Web Vitals, organic rankings, keyword volumes, or conversion totals are asserted here.

## Inventory and verified baseline

- Stack: React 19, React Router, Vite, `react-helmet-async`, custom Node prerender, Vercel clean URLs and rewrites. There is no CMS in this repository; routes and metadata are maintained in source. GA4 and Meta Pixel are loaded in `index.html`; click/form events are called from components. Account-side receipt and deduplication were not verified.
- The complete **212-route local inventory** is in [SEO_ROUTE_INVENTORY.md](SEO_ROUTE_INVENTORY.md) and [SEO_ROUTE_INVENTORY.csv](SEO_ROUTE_INVENTORY.csv). It records URL, page type, local generated status, indexability, canonical, title, description, H1, primary intent, internal links and sitemap inclusion. `200 local prerender` is explicitly not a deployed HTTP status.
- The live sitemap contained **178 URLs** at audit time. All 178 returned HTTP 200 in a HEAD crawl and none redirected; the raw crawl is [SEO_LIVE_SITEMAP_STATUS_2026-10-03.csv](SEO_LIVE_SITEMAP_STATUS_2026-10-03.csv). Live robots and sitemap returned 200; a random unknown URL returned 404. HTTP and non-www redirected to HTTPS www. These checks do not prove indexing or that all other URLs work.
- The live Arabic SAT URL had Arabic metadata and self-canonical but an English H1/body; it was in the live sitemap. The local production sitemap now has **89 unique HTTPS www URLs** with no admin, enquiry, diagnostic result, verification, or untranslated Arabic URLs. It emits no synthetic `lastmod` date. The published sitemap will change only after deployment.
- Before-change local production metadata for seven representative routes is preserved in [SEO_BASELINE_2026-10-03.md](SEO_BASELINE_2026-10-03.md).

## Redirects, content gaps and external work

No URL changes were required, so **no new redirect map** is proposed. Preserve the configured `/sat-preparation` → `/sat-preparation-sharjah` permanent redirect and the existing `/webinar` temporary redirect. Test production redirect status and hop count after deployment; local Vercel configuration alone does not prove deployed behaviour.

Content gaps that need approved facts and dedicated space: detailed SAT format and teaching approach; subject levels/curricula actually taught; course duration/mode/prerequisites/fees where confirmed; Arabic translations beyond the homepage; and genuinely distinct reasons for any Dubai-focused page. Do not add thin city or neighbourhood pages to fill these gaps. Review existing SAT and tuition articles for duplicate intent after Search Console data is available.
